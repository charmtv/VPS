专业的VPS流量消耗管理工具，支持多线程并发下载、实时流量监控、流量目标管理、网络测速、系统服务集成等功能。

## ⚡ 一键安装

> 请使用 `root` 用户运行，或在命令前加 `sudo`。

### 方法1：使用curl（推荐）
```bash
curl -fsSL https://xh.813099.xyz | bash
```

脚本会保留环境检测、依赖安装和系统更新流程；安装完成后直接进入控制台，无需再次输入启动命令。

### 方法2：使用wget
```bash
wget -qO- https://xh.813099.xyz | bash
```

### 方法3：手动安装
```bash
# 下载安装脚本
wget -O install.sh https://xh.813099.xyz
chmod +x install.sh
bash install.sh
```

## 🎯 快速开始

以后再次使用时，直接输入快捷键启动：

## 使用说明

### 基本操作
```bash
# 启动工具
xh

# 直接运行主脚本
bash /root/vpsflow.sh
```

### 键盘操作

| 按键 | 作用 |
|------|------|
| `↑` / `↓`（或 `k` / `j`） | 上下选择，到头循环 |
| `Enter` | 执行当前选中项 |
| `1`-`9` / `A` / `B` / `U` / `0` | 直达对应功能 |
| `Q` | 退出控制台 |

### 服务管理
```bash
# 查看服务状态
systemctl status vpsflow

# 手动启停服务
systemctl start vpsflow
systemctl stop vpsflow
```

### 配置文件位置
```text
/root/vpsflow.sh               # 主脚本
/root/vpsflow_config.conf      # 主配置文件
/root/vpsflow_shortcut.conf    # 快捷键配置
/root/vpsflow_target.conf      # 流量目标配置
/root/vpsflow.log              # 运行日志
/run/vpsflow/                  # 运行期状态（重启后自动清空）
```

## 高级配置

### 下载URL预设
启动服务时可选择预设URL（均为境外节点）：

| 选项 | 节点 | 说明 |
|------|------|------|
| [1] | 香港 Datapacket 100MB | 推荐，低延迟 |
| [2] | 日本东京 Datapacket 100MB | 亚洲优选 |
| [3] | 新加坡 OVH 1GB | 大文件模式 |
| [4] | 德国 Hetzner 1GB | 欧洲高速 |
| [5] | 美西洛杉矶 Datapacket 1GB | 北美 |
| [6] | 法国 OVH 10GB | 超大文件 |
| [7] | 上次使用 | 自动记忆上次配置 |
| [8] | 自定义URL | 手动输入任意下载链接 |

### 流量目标管理
在菜单中选择 `[4] 流量目标` 可以：
- 设置流量消耗目标（单位：GB）
- 查看当前消耗进度（渐变进度条显示）
- 启用自动停止（达到目标后自动停止服务，每 5 分钟检查一次）

> 修改目标值时会保留原有的自动停止开关，并按新目标重新开始计数。

### 自定义快捷键
在主菜单中选择 `[A] 快捷键管理` 可以：
- 重新安装快捷键
- 自定义快捷键名称
- 删除快捷键

### 线程数配置
- 工具会根据CPU核心数自动推荐线程数
- 推荐值：CPU核心数 × 2
- 最大值：CPU核心数 × 4

## 🗑️ 完全卸载

在主菜单选择 `[U] 卸载全部服务`，或运行：
```bash
bash /root/vpsflow_uninstall.sh
```
`/root/vpsflow_uninstall.sh` 会在安装后首次进入控制台时自动生成。

## 🔍 故障排除

### 快捷键无反应
1. 检查快捷键是否存在：`ls -la /usr/local/bin/xh`
2. 检查PATH环境：`echo $PATH | grep /usr/local/bin`
3. 手动测试：`/usr/local/bin/xh`
4. 重新安装快捷键：在主菜单选择 `[A] 快捷键管理`

### 服务无法启动
1. 检查日志：`journalctl -u vpsflow -f`
2. 检查权限：确保以root权限运行
3. 检查网络：确保能访问下载URL
4. 重新安装：重新运行安装脚本

### 监控显示错误
1. 运行 `[7] 功能诊断` 自动检测问题
2. 检查网络接口：`ip link show`
3. 检查权限：确保有读取网络统计的权限

### 更名
- 🧾 **移除全部作者署名与推广内容** - 界面、脚本、文档中的作者名与交流群入口已全部清除，产品名统一为「VPS 流量消耗管理工具」

### 界面重构
- 🕹️ **竖排简约主菜单** - 13 项功能单列竖排，名称与说明分列对齐，整屏 22 行
- ⌨️ **方向键选择** - ↑↓ 选择并循环、Enter 确认、按键直达，兼容 `j` / `k`
- 💡 **每项自带说明** - 名称右侧直接标注用途；窄终端下改在底部单行显示
- ▪️ **选中条不拉满屏** - 反色条宽度按菜单内容算出，不再横贯整个终端
- 📐 **统一绘制层** - 新增 `ui_title` / `ui_kv` / `ui_item` / `ui_rule` / `ui_ask` 等组件，全部界面改用同一套排版，不再出现宽度不一的边框
- 🔄 **菜单数据单一来源** - 交互菜单与非交互降级菜单共用同一份选项数据，不会再出现两处不同步
- 📱 **窄终端适配** - 状态行在窄屏下压缩次要信息，说明列自动折叠
- 🎨 **监控界面重做** - 实时监控与高级监控改用与主菜单一致的排版，进度条宽度随终端自适应

### 缺陷修复
- 🐛 **修复主菜单目标行报错** - `get_target_summary` 此前被调用却从未定义，主菜单每次刷新都会失败；现已实现并补上进度百分比
- 🐛 **修复速率显示恒为 0** - 主菜单速率原先按整数除法算 MB/s，1MB/s 以下一律显示 0；改为自动换算单位
- 🐛 **修复速率统计取错网卡** - 改为优先使用配置中已保存的接口，与监控界面保持一致
- 🐛 **修复停止服务的残留清理** - `pkill` 匹配的是早已弃用的 `curl.*cloudflare`，改为匹配实际的下载线程
- 🐛 **修复进度条除零** - `generate_bar` 在最大值为 0 时会触发除零错误
- 🐛 **修复改目标时静默关闭自动停止** - 设置新目标会保留原开关并重新挂载检查任务
- 🐛 **修复监控界面目标进度算错** - 网卡计数回绕时的容错逻辑存在重复累加
- 🐛 **修复输入流关闭后空转** - 菜单读键区分超时与 EOF，输入结束时正常退出
- 🐛 **修复进度条宽度计算** - 块状字符（`█░─`）此前被当作双宽字符，导致右对齐错位

### 安全与性能
- 🔒 **运行期状态文件移出 /tmp** - 速率采样状态改用 `/run/vpsflow`（0700），避免可预测路径被抢占
- ⚡ **状态区减少进程开销** - 主机名与 CPU 核数只取一次，磁盘占用 30 秒刷新一次，读网卡计数改用内建重定向
- 🧹 **合并重复代码** - 下载源表、更新源、流量目标进度计算、自动停止开关各自收敛为单一实现
- 🧼 **诊断流程简化** - 功能诊断的采样测试不再嵌套一层转义脚本，直接在当前 shell 中采样

### 其他
- 🛠️ **补齐 CI 配置** - 新增 GitHub Actions，自动执行 `bash -n` 与 shellcheck（含生成脚本）
- 🧩 **cf-worker 路由收紧** - 白名单改用 `Map`，避免 `constructor` 等原型链属性被误判为命中；保留旧文件名路由供老客户端升级

### 从旧版本升级

新版启动时会自动完成迁移，无需手动操作：

| 旧 | 新 |
